### 배경

우리 회사의 좋은 복지 중 하나는 중식 식대 지원이다.

점심을 먹고 내역을 작성해야 한다.

&nbsp;

내역을 작성하려면 사내 서버에 있는 엑셀 파일에다가 작성해야 한다.

방화벽 때문에 외부에서는 접근 불가하기 때문에

점심을 먹고 금액, 식당, 결제자 정보를 카톡 나에게 보내기로 내역을 기록했다.

회사에 복귀해 작성내용을 다시 확인해서 엑셀에 기록.


맥에서는 저장도 원활히 되지 않아서 내 로컬 PC에 옮기고 다시 사내 서버 PC로 옮기는 불편함이 있었다.

&nbsp;

### 어떻게 만들까

1. 사용자의 입력 정보는 최대한 유지하자.
    - 이질감을 최대한 없애기 위해.
2. 로그인 / 회원가입 등 기능은 빼자 
    - 단기 프로젝트이고, 점심식대 내역은 이름만 나올 뿐 중요한 개인정보가 없다.
3. 이번달 잔액 정보를 나타내자 
    - 항상 궁금한 정보이므로.
4. _식대를 입력하면 사내 서버 파일에 바로 반영되게 하자._
5. _점심조 뽑기 기능을 넣자._
6. 모바일 앱처럼 만들자 (PWA)
7. 외부에서도 접속해서 작성할 수 있도록 하자.





4번에 가장 충실하고 싶고, SMB로 접속하는 라이브러리가 vanilla js환경에서 가장 매끄럽게 잘 될 것 같았다.
그래서 `express.js`로 개발하기로 결정


### 삼바 프로토콜 ..?



> SMB(Server Message Block) 프로토콜은 **네트워크 상에서 파일, 프린터, 포트, 기타 리소스를 공유**하기 위해 사용되는 **애플리케이션 계층 프로토콜**


|||
|------|---|
|목적|네트워크를 통해 파일 및 리소스를 공유|
|사용처|Windows 환경에서 주로 사용되며, macOS나 Linux에서도 지원됨|
|기능|1. 파일 읽기/쓰기|
||2. 디렉터리 탐색|
||3. 프린터 공유|
||4. 사용자 인증 및 접근 제어|
|주요 특징|클라이언트-서버 모델 사용|
||TCP 포트 445 사용 (구버전은 137~139번 포트 사용)|
|버전|SMB1, SMB2, SMB3 등|

### 작업 로직

1. express.js에서 smbClient를 통해서 파일들을 가져오기.
    - 윈도우 서버라 그런지 자모분리 현상을 해결하면서 진행함
2. 로그인한 유저의 이름이 포함된 엑셀 파일 찾는다.
    - 새로고침할 시 smb연결이 끊기는 에러가 발생..
        
        ⇒ smbClient 객체를 생성하는 함수를 따로 만들어서 매 요청 시 이 함수를 실행해 새 연결을 시도한다

3. 엑셀파일 내부 데이터 읽기
    1. 엑셀파일을 버킷 다운로드(로컬에 저장) 

        메인 페이지 최초 진입 시에만 저장하고, 달 선택 시 이미 다운로드 된 엑셀 파일에서 검색되도록 바꾸기
        
        문제점 : 엑셀 조회할 때 전반적으로 너무 느림

    2. Stream으로 읽고 쓰기

        조회 속도 향상, 내용 업데이트 기능 정상작동


-> Stream으로 I/O 작업이 가능해져 굳이 따로 파일을 저장하지 않고도 괜찮은 속도였다.

&nbsp;

하지만, 간과했던 부분은 _외부접속_ 이다.

내가 작업한 와이파이는 사내 와이파이라 읽고 쓰기가 가능했던 것.

핫스팟이나 외부접속 시 위 기능을 하지 못해 무용지물이 되버린다.
